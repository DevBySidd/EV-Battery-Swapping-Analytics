# EV-Battery-Swapping-Analytics

⚡ EV Battery Swapping Analytics

Data-Driven Analysis for Improving Electric Vehicle Battery Swapping Operations

📌 Project Overview

This project focuses on analyzing EV battery swapping operations to identify operational inefficiencies, battery shortages, station performance issues, and swap failures.

Using Python for data analysis and Power BI for dashboard development, we transformed operational data into meaningful insights and business recommendations.

🎯 Project Objectives

- Analyze overall battery swapping performance.
- Identify high-risk and low-performing stations.
- Understand battery availability and shortage patterns.
- Investigate major reasons behind failed swaps.
- Analyze the relationship between charging time and failure rates.
- Provide actionable business recommendations.

📊 Key Findings

Metric| Result
Total Swap Attempts| 3,814,982
Failed Swaps| 228,307
High-Risk Stations| 35
High-Risk Failure Contribution| 45.54%
High-Risk Station Failure Rate| 8.18%
Other Station Failure Rate| 4.89%
Charging Time vs Failure Rate Correlation| 0.709

Important Insights

- Battery unavailability accounts for 61.18% of failures at high-risk stations.
- Battery shortages peak between 2 PM and 4 PM.
- High-risk stations contribute a significant share of total swap failures.
- Longer charging times are positively correlated with higher failure rates.
